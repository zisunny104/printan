# 熱感照片階調

圖片元素的 `toneCurve` 選用欄位：

- `none`（預設）：維持既有處理，不修改舊範本。
- `photo-readable`：灰階後，以 `16 + 239 × (gray / 255)^0.72` 提亮暗部，純白保持 255，再依元素既有取樣方式轉成黑白網點。

- `photo-detail`：灰階後先做局部對比（以較大範圍的模糊為基準，把主體與背景的亮暗差拉開），再以 `255 × (gray / 255)^1.7` 線性化，最後用 3×3 反銳化拉開邊緣。線性化是因為抖色的網點覆蓋率對應線性亮度，灰階值直接當覆蓋率會讓中間調與亮部偏白；不再做自動色階，原本接近純白的區域維持白色。整張同色時結果仍是同一個灰階。

取樣方式（`ditherMode`）另有兩個選項：`serpentine`（來回掃描的誤差擴散，累積誤差夾回 0–255，減少斜向蟲紋）與 `blue-noise`（藍噪聲有序抖色，沒有格紋與蟲紋，固定矩陣、每次結果相同）。照片建議搭配 `photo-detail`＋`blue-noise` 或 `serpentine`；舊檔維持 `floyd-steinberg` 不變。

編輯器「調整」→「熱感照片階調」可切換「原始」或「易辨識（提亮暗部）」。只在熱感模擬與列印套用；一般螢幕預覽保留原圖色調。亮度、對比、反相與取樣方式保持獨立設定，匯出與重新開啟 `.ptan` 會保留選項。未指定或不認識的值不套曲線。

這是照片的建議處理，不是整張單據的濃度調整。文字、Logo、條碼與心得圖片不應套用此階調。實際墨點擴張仍受印表機與紙張影響，需要用同一台設備試印亮、中、暗三類照片確認。
