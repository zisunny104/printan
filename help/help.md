## 基本操作

- 新增元素：工作區下方工具列，或左側「版面結構」的 **＋**。點選元素後到右側「元素設定」調整。
- 排序與尺寸：拖曳元素外框換順序；拖曳間隔、圖片、條碼的下緣調高度；拖曳欄與欄之間的把手調欄寬。
- 文字：選取後再點一次可直接在紙上編輯；點紙外空白處取消選取。
- 工作區：白色範圍就是實際可列印範圍，尺規以它的左緣為 0；灰虛線是切刀安全線（低於此線的內容切紙時可能被切到）。**1:1** 是實際大小。
- 存檔：版型自動存在這台電腦的瀏覽器；「匯出」可存成 `.ptan` 或 PDF。

## 版面元素

| 元素 | 用途 |
| --- | --- |
| 文字 | 可混用粗體、斜體、底線等樣式 |
| 圖片 | 自動轉成 1-bit 點陣 |
| 間隔 | 一段空白高度 |
| 分隔線 | 實線、虛線、點線 |
| 條碼 | QR Code、Code128、EAN-13 |
| 多欄 | 欄寬比例 1/1、2/1、1/2、1/1/1，欄內可再放任何元素 |
| 圖文 | 一張圖片靠左或靠右，文字繞著圖片排 |

- 圖片：選取後拖曳圖片邊緣或下角的把手調整寬度（下角加 [[Shift]] 可自由拉高）；「元素設定」可直接輸入寬度百分比，並選靠左／置中／靠右，把手位置會跟著對齊方式變。
- 圖片格式支援 PNG、JPEG、GIF、WebP（不含 SVG），一份版型最多 100 張。
- 多欄：工作區每一欄上方有 **＋**，點一下把該欄對半分成兩欄（最多 6 欄）；雙擊兩欄之間的分隔線，右欄內容併入左欄。
- 「版面結構」列出所有元素；「第 N 欄」是容器，點選後新元素會加到那一欄。
- 同層元素可用列上的上移／下移，或在工作區拖曳排序。
- 在「版面結構」拖曳列可換層：放到元素列上是插在它前後，放到「第 N 欄」列上是移進該欄。

## 圖文段落

新增元素選「圖文」，會得到一張圖片加一段文字，文字繞著圖片排。

- 圖片：「元素設定」選擇或更換圖片，用箭頭選靠左或靠右，「圖片寬度」是佔欄寬的百分比；也可在工作區拖曳圖片的把手調整。
- 文字：內容與段落樣式跟一般文字相同。
- 編輯文字時，文字框會暫時撐滿整欄寬，離開編輯後才恢復繞圖排列。
- 限制：每個圖文段落只有一張圖；不能跨欄；不支援直書。

## 文字樣式

- 在紙上或「元素設定」的文字框選取一段字，再套用粗體、斜體、底線、刪除線、反相（黑底白字）。
- 選取範圍可各自設定字體與字級（dot）；沒選取時設定的是整個文字元素的預設值。
- 對齊（靠左／置中／靠右）是整個文字元素的設定。
- 橫書／直書：在「元素設定」的文字設定按橫書或直書圖示。直書由上而下、行由右而左；括號、破折號會轉向，數字與英文逐字直立排列。
- 直書目前只是基本功能，實際列印效果請先用測試列印確認。

## 文字與變數

- 文字、圖片來源、條碼內容可寫 `{{名稱}}`，列印時換成實際資料。
- 「變數與預覽資料」會列出用到的變數，填入測試值即可在工作區預覽。
- 「批次資料」貼上 JSON 陣列或 CSV，每筆資料輸出一頁 PDF（Mail Merge）。CSV 第一列是變數名稱，之後每列一筆；不是以 [ 或 { 開頭就當 CSV。圖片欄位只支援 https 網址；對方網站不允許跨網域讀取或載入失敗時，該圖會被略過並提示。

## 字體

- 可選內建字體、等寬字體，或授權後使用本機字體。
- `.ptan` 預設只記錄字體名稱；匯出時勾選「內嵌字體」會帶入用到的等寬開源字體（只含用到的字），換電腦也能照樣顯示。
- 本機字體因授權不會內嵌，換電腦需自行安裝。
- 網頁字體沒載入成功時，預覽與列印改用系統字體，並在工作區上方提示。

## 條碼

- 支援 QR Code、Code128、EAN-13；內容可含 `{{變數}}`。
- 一維條碼可切換是否顯示明碼。
- 內容格式不符時會在「元素設定」提示；含變數的內容要套用資料後才會檢查。

## 列印與校正

- 「列印設定」可連線印表機（USB 或序列埠，需 Chrome／Edge），並設定走紙、切紙、可列印點數、邊距校正。
- 可列印點數留空即用內建規格；列印內容會置中補白到所有紙寬中最大的點數再送出。
- 直連印表機才有邊距校正；未連線時「列印」走系統列印對話框。系統列印與 PDF 只能縮窄可列印寬度，沒有左側補白，邊距校正對它們無效。
- 邊距校正：按「校正紙」印出量尺，量出左右實際留白（mm）填入該紙寬的兩格；兩格都填才生效，清空即不校正。
- 測試列印可確認走紙與切紙位置；切紙前走紙不夠，切刀會切到剛印完的內容。
- 熱感圖示切換為 1-bit 抖動預覽，接近實際列印效果。
- 單張輸出最高 65535 點（約 8 公尺）；內容更長時會先詢問，超出部分會被截掉。
